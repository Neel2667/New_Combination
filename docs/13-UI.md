# 13 — UI

The UI is an operator workspace for the visual system, not the place where core business rules live.

## Initial areas

- Dashboard
- Asset Pantry browser
- Asset detail and license panel
- Visual Intent inspector
- Composition candidate viewer
- Composition timeline/editor
- Render queue
- Preview/Critic panel
- Usage and compatibility insights

The UI should make the composition understandable: users should be able to see why ingredients were combined, what constraints were applied, and what the Critic found.
