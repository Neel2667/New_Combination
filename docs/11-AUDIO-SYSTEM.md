# 11 — Audio System

Audio is part of composition, not a post-processing afterthought.

## Inputs

- narration generated with Edge TTS
- background music
- sound effects
- timing markers

## Composition

The audio system represents timing and relationships between narration, music and SFX. Visual timing can reference narration word/phrase boundaries when available.

## Goals

- clear narration
- intentional music ducking
- synchronized SFX
- no accidental clipping
- deterministic timing
- reusable audio metadata
