# 03 — Asset Pantry

The Pantry is the controlled visual world from which compositions are built.

## Ingredient families

- Backgrounds
- Stock video
- Photos
- Illustrations
- Icons
- SVG graphics
- Character/mascot elements
- Typography treatments
- Shapes and UI primitives
- Textures and overlays
- Procedural graphics
- Transitions
- Particles/effects
- Music
- Sound effects
- Remotion components
- HTML/SVG/Canvas compositions

## Philosophy

An ingredient is not judged as a finished design. Its value is contextual: an apparently ordinary background can become excellent when paired with the right subject, typography, motion and audio.

Therefore the system optimizes **combinations**, not isolated asset ratings.

## Diversity

The Pantry should support multiple visual styles and energy levels so the Matchmaker can avoid repetitive output.
