# 15 — Quality Gates

A composition cannot become production output by merely rendering successfully.

## Gates

1. Schema validation
2. Asset existence validation
3. License eligibility
4. Media compatibility
5. Timing consistency
6. Audio sanity
7. Composition hierarchy/readability checks
8. Deterministic render check
9. Visual Critic evaluation
10. Final output validation

A failed gate blocks promotion to the next stage and records the reason.
