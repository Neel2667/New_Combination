# TASK-004 — Asset Search

## Objective
Make Pantry ingredients retrievable using semantic and visual metadata.

## Search dimensions
- subject
- tags
- visual function
- style
- mood
- energy
- complexity
- orientation/direction
- aspect ratio
- text-safe area
- license eligibility

## Acceptance criteria
- hard filters exclude blocked assets
- metadata filters are testable
- ranked results expose why an asset matched
- recent-use penalties can be applied
