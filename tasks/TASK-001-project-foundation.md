# TASK-001 — Project Foundation

## Objective
Create the minimal application foundation without implementing creative logic.

## Outputs
- TypeScript project structure
- frontend/backend boundaries
- shared domain package
- environment configuration
- test runner
- lint/typecheck scripts
- basic health endpoint

## Constraints
- Follow `PROJECT_RULES.md`.
- Do not add AI, rendering, database features or UI beyond the foundation.
- Do not introduce a second framework or database.

## Acceptance criteria
- project installs cleanly
- typecheck passes
- tests pass
- backend starts
- health endpoint responds
- frontend builds
- boundaries are documented
